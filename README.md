# A-MEM 论文复现笔记与评测结果

对论文 [A-Mem: Agentic Memory for LLM Agents](https://arxiv.org/pdf/2502.12110)（NeurIPS 2025）的
课程复现记录：源码走读、本地部署、批量评测、与论文 Table 1 的分题型对照。

> **上游仓库**：复现代码基于作者开源的 [WujiangXu/A-mem](https://github.com/WujiangXu/A-mem)。
> 本仓库只收录我个人的分析笔记、评测结果与汇报材料，不含上游源码。

## 我做了什么

1. **源码走读**：通读执行路径约 440 行，定位记忆写入（`add_note`）、检索、演化三处核心实现 → [docs/代码走读笔记.md](docs/代码走读笔记.md)
2. **本地部署**：通过 Ollama 接入 Qwen2.5-1.5B、Llama3.2-1B/3B 三个基座模型；嵌入模型 all-MiniLM-L6-v2 → [docs/本地Ollama运行指南.md](docs/本地Ollama运行指南.md)
3. **数据核查**：解析评测集 LoCoMo（10 段对话 / 272 session / 5882 轮 / 1986 QA），统计五类题型分布与不平衡情况 → [docs/数据评估标准.md](docs/数据评估标准.md)
4. **批量评测**：跑通 4 段对话共 757 道题，统计 14 项指标（EM / F1 / BLEU1-4 / ROUGE1/2/L / METEOR / SBERT / BERT*）→ [docs/指标含义说明.md](docs/指标含义说明.md)
5. **论文对照**：与论文 Table 1 的 Llama 3.2 3B 块做分题型对比并归因偏差 → [docs/论文对比结果.md](docs/论文对比结果.md)

## 主要结果

模型 Llama 3.2 3B，`retrieve_k=10`，ratio=0.4（4/10 段对话，757 题）：

| 类别 | 论文 F1 | 本地 F1 | 差值 |
|---|---|---|---|
| Multi Hop（多跳） | 17.44 | 11.00 | −6.44 |
| Temporal（时序） | 26.38 | 13.37 | −13.01 |
| Open Domain（开放域） | 12.53 | 6.28 | −6.25 |
| Single Hop（单跳） | 28.14 | 16.78 | −11.36 |
| Adversarial（对抗） | 42.04 | **45.13** | **+3.09** |
| **整体** | — | **21.38** | — |

**结论**：题型排序与论文完全一致（`Adversarial > Single Hop > Temporal > Multi Hop > Open Domain`），
说明方法行为特性被复现；除对抗类外，绝对分值系统性偏低 6–13 个百分点。

**偏差归因**（详见 [docs/论文对比结果.md](docs/论文对比结果.md)）：

- 数据范围：论文用全量 10 段对话（约 1981 题），本地仅前 4 段（757 题）
- 推理精度：论文服务化部署（fp16），本地 Ollama 默认 q4 量化，3B 模型对量化较敏感
- 指标实现：`utils.py` 自实现的 BLEU 平滑与分词口径可能与论文不同
