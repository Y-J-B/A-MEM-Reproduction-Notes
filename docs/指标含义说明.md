# A-Mem 评测指标说明

对应文件：`results_robust_ollama_llama32_3b.json`（llama3.2:3b，ratio=0.1，199 题）

## 指标对照表

| 指标 | 看什么 | 侧重什么 | 变大说明什么 |
|---|---|---|---|
| `exact_match` | 整句是否与答案**字面完全一致**（不剔除标点） | 严格正确性（0/1 二值） | 变成 1 = 一字不差（含标点格式）答对 |
| `f1` | **单个词**在预测和答案中的重合 | 准确率与召回率的平衡 | 回答覆盖了答案更多词、且废话更少 → 更可能答对 |
| `bleu1` | 单词级精确率 + **答短了就扣分** | 用词准确、长度到位 | 用词更准、且没有无谓的省略或啰嗦 |
| `bleu2/3/4` | **连续 2/3/4 个词**的精确率 | 短语与长句的还原度 | 越长片段被复现 → 措辞高度贴合答案（短答案场景很难升高） |
| `rouge1_f` | 单词重合的 F 值（同 `f1`） | 内容覆盖 | 与 `f1` 同义，两者高度冗余 |
| `rouge2_f` | **连续两个词**的重合 | 短语/措辞还原 | 出现了和答案一样的短语（如 `may 2023`），而非只是单词碰巧相同 |
| `rougeL_f` | 最长公共子序列（允许中间断开） | **语序结构** | 词的顺序与答案一致，不是把词打乱后拼凑 |
| `meteor` | 词干 + 同义词匹配 | 宽松版词面匹配 | 表达贴近答案，即使形态变化（`paint`/`painting`）也算 |
| `sbert_similarity` | 整句向量余弦相似度 | **语义正确性**（跨措辞） | 意思更接近答案，即使说法完全不同 |
| `bert_precision/recall/f1` | 语义相似度（计算失败） | — | **全 0，无效数据，不要引用** |

## 一句话抓重点

- `exact_match` 看「是否完全对」；`f1` 看「内容答全没」；`bleu1` 看「用词准不准、长度够不够」；`rouge2_f` / `rougeL_f` 看「短语和语序像不像」；`sbert` 看「意思对不对」。
- 除 `sbert` 外，其余全被**措辞**绑架：抄上下文会虚高，换同义词会虚低。
- 「变大」只代表**更像参考答案的写法**，不代表一定更对；判断模型是否真进步，要看 `f1` 与 `sbert` 是否同时上升。

## 注意点：`exact_match` 口径极严（标点敏感）

`exact_match` 是**严格字符串比较，不做归一化**，而 `f1` / `rouge_*` 会先剔除标点、统一大小写。
因此仅一个标点或格式差异，就会让 `exact_match` 从 1 掉到 0。

实例（`results_robust_ollama_llama32_3b.json` 第 5256 行起）：

| 字段 | 内容 |
|---|---|
| prediction | `Being present and bonding with her family.`（末尾有句号） |
| reference | `Being present and bonding with her family`（无句号） |

| 指标 | 值 | 说明 |
|---|---|---|
| `f1` | 1.0 | 分词后 8 个词全部命中 |
| `rouge1_f` / `rouge2_f` / `rougeL_f` | 1.0 | 去标点后完全一致 |
| `bleu1` | 0.875 | 标点被计为一个 token，精确率 < 1 |
| `exact_match` | **0** | 整句不一致（多了一个 `.`） |
| `sbert_similarity` | 0.970 | 语义几乎相同 |

结论：

1. `exact_match = 0.0905`（约 18/199）**明显低估**了真正答对的题数——结尾多句号、少冠词、大小写不同、日期格式不同都会被判 0。
2. `exact_match` **不能当作准确率**，也不宜与论文里的 Accuracy 直接对比。
3. 报告里建议以 `f1` + `sbert_similarity` 为主，`exact_match` 仅作「严格一致率」的参考值。

## 解读要点

1. F1 均值 0.2609、中位数仅 0.0952 —— 过半题目几乎零词面重合，少数满分题抬高了均值，属「偶发答对」。
2. 分题型看：多跳（`category_1`）F1 仅 0.087，单跳（`category_4`，70 题）最高 —— 短板在跨记忆整合。
3. `bert_*` 三项全 0 是本机 `bert_score` 初始化失败（`utils.py` 中异常被吞），不是模型表现。
4. 汇报口径：不要写「准确率 26%」，应写「词面 F1 0.26，且过半题目无词面重合」。
